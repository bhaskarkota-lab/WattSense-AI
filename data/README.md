# WattSense AI™ — Dataset Repository Documentation

## 1. Overview
This directory contains the experimental datasets utilized by the WattSense AI™ platform for training multi-horizon electricity forecasting models and evaluating wastage detection baselines.

## 2. Dataset Structure

- `data/raw/uci/energydata_complete.csv`:
  - **Source**: UCI Machine Learning Repository — Appliances Energy Prediction Dataset.
  - **Context**: 10-minute continuous telemetry from a single residential household in Stambruges, Belgium over 4.5 months (19,735 observations).
  - **Academic Note**: This dataset models sub-hourly residential appliance draw and ambient indoor/outdoor climate parameters for one real residential property.

- `data/interim/uci_interim_cleaned.csv`:
  - Intermediate data generated by Phase 2 preprocessing, verifying strict 10-minute monotonic timestamps, missing-value imputation, and unit standardization (Wh to kWh).

- `data/processed/uci/uci_features.csv`:
  - Master feature store containing lag features ($t-1$, $t-6$, $t-144$), cyclical temporal encodings (hour sin/cos, day of week sin/cos), and rolling statistics strictly preventing future target leakage.

- `data/processed/sgcc/sgcc_clean.csv`:
  - State Grid Corporation of China (SGCC) daily smart meter consumption benchmarking data used for cross-dataset validation.
